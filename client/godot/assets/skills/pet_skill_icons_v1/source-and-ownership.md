# Beastbound 宠物技能图标 v1

## 来源与所有权

- 本目录中的图标均为 Beastbound Odyssey 本次独立制作的原创生成美术。
- 生成工具：OpenAI ImageGen。
- 参考图只用于理解“暖暗手绘商业游戏技能图标”的完成度和信息密度；
  没有复制参考作品的角色、图标、边框、文字或布局资产。
- 项目运行时只使用 `runtime/`；`source/generated/` 保留规范化的 512×512
  源图，ImageGen 原始输出路径和提示词记录在 `asset-manifest.json` 与
  `source/prompts/`。
- 图标不含技能名、等级、类别徽标、稀有度或外层技能槽框；这些由 UI
  独立呈现，方便以后重平衡和本地化。

## 生产合同

- 每个正式主动/被动技能必须有 exact-ID 独立图标。
- 源图：512×512 PNG；运行图：256×256 PNG。
- 图标采用暖暗棕黑满幅背景，禁止透明棋盘格、白边、水印、emoji、
  战斗帧裁切、宠物头像裁切和临时复用图。
- 运行时路径：
  - 主动：`runtime/active/<skillId>.png`
  - 被动：`runtime/passive/<skillId>.png`
- 需要在 32×32 缩略检查中仍能区分核心语义。
- 图标映射写在权威主动/被动目录的 `presentation.iconPath`；资产 manifest
  只记录文件、哈希、尺寸、来源和审核状态，不重复技能机械。

## 替换路径

若未来人工重绘，保持 skill ID 和 runtime 路径不变，更新 512 源图、
256 运行图、提示/作者记录、SHA256 和视觉审核证据即可。不得只替换运行图
而丢失可追溯源。

## 审核状态

工程完整性与小尺寸辨识由自动检查负责；美术最终状态保持
`owner_review_pending`，直到项目所有者通过真实 1280×720 技能页录像验收。
