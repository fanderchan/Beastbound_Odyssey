# Market Awakened V1 source and ownership

- Runtime purpose: Beastbound Odyssey marketplace page backdrop at the normal
  `1280x720` PC client size.
- Authorship: generated for this repository with OpenAI's built-in image
  generation tool on 2026-08-07, then resampled locally to the runtime size.
- Header icon: reuses the project's original ImageGen marketplace-scale icon,
  copied together with its `1254x1254` chroma source into this bundle so the
  marketplace remains independently reproducible from a clean checkout.
- Ownership: original project-directed output. It does not contain copied
  pixels, logos, text, characters, pets, item icons, or interface controls from
  the supplied commercial-game screenshots.
- Reference boundary: the user screenshots informed only the broad hierarchy of
  wood/bamboo framing, pale parchment, restrained leaves, and corner marketplace
  props. All interactive labels, cards, buttons, counters, and item art remain
  live Beastbound controls and owned runtime assets.
- Replacement path: replace each runtime/source pair together and update its
  SHA-256 entry in `asset-manifest.json`; the panel layout does not depend on
  baked-in text.
