## 隔离与安全

录像控制器只构造本次验收所需的确定性内存档案：

- 使用全新独立 `user://`，没有读取或覆盖正常玩家存档；
- `profile_save_enabled=false`；
- 没有启动后端，没有访问 MySQL；
- 没有真实消费宠物蛋、骑宠资格证、钻石或石币；
- 没有把 QA 说明、录制步骤或调试浮层画进玩家界面；
- 退出后隔离用户目录仍为零文件。

因此本片验证的是当前玩家可见 UI、入口、数据投影和头像一致性，不冒充在线服
真实付费结算，也不扩大为融合宠玩家入口或生产发布批准。34 个正式目录形态能被
普通 Main 加载；曜冠角兽、苔垒角兽两个融合候选仍位于隔离包，不计入本片的普通
Main 消费者覆盖。

## 本轮发现并修复的问题

首次自审发现培养窗口在“已选择宠物但预览没有返回 lines”时只显示宠物名，正文
为空。现改为按预览正文实际行数判断：没有明细行时必须显示模型返回的资格／原因
消息。该修复只补 UI 反馈，不修改转生公式、材料、价格或服务端权威规则。最终片
已显示完整满石转生预览。

录像工具同样在首版转码中拒绝了全范围 `yuvj420p` 输出，最终强制为播放器兼容的
有限范围 `yuv420p`；工具会检查分辨率、帧率、时长、像素格式、音频、完整解码、
截图、联系表和 SHA，任一失败都不会把成片标为通过。
