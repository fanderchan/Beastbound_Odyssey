# Phase 413：地脉守护兽锁定蓄力决策窗

## 结论

本阶段完成 P1.5 的第一条可发布切片：只有服务端权威登记的 `earth_vein_guardian_group` 会在第一回合末由
岩脉守护兽锁定一只在场宠物，并在第二回合末发动一次 `岩晶冲撞`。玩家可以用既有防御、换宠或控制
三类决定改变结果；普通队伍 PVE、切磋、其他守护战和既有自动战斗都不获得这套机制。

这不是 P1.5 全部完成。当前只证明一只正式 Boss 具备可读的两回合决策窗；其他 Boss 的阶段变化、驱散
与资源窗口，以及 PvP 的目标优先和元素策略仍需后续切片。

## 参考意图与原创边界

StoneAge 8.0 只作为成熟回合制游戏“先给信息，再允许反制”的行为参考。本阶段没有复制其源码、数值、
地图、美术或具体 Boss 机制。Beastbound 的原始规则保持简单：首回合明确锁定，下一回合只结算一次，
并完全复用现有防御、换宠、状态控制、伤害与元素解释器，不另造隐藏免控、额外倍率或临时资源。

## 服务端权威合同

| 项目 | 固定行为 |
| --- | --- |
| 启用来源 | 权威遭遇同时给出 `earth_vein_guardian_group` 与 `guardian_targeted_charge_v1` |
| Boss 身份 | 固定槽位 `enemy.front.3`；必须具备 `pet_bui_charge` |
| 第一回合 | 最后行动，优先锁定仍存活且在场的宠物；没有宠物时才选人物 |
| 第二回合 | 最后行动，只攻击已锁定 actor，不重新选人 |
| 防御 | 复用既有 `0.45` 防御伤害系数，没有 Boss 专用减伤公式 |
| 换宠 | 原目标离场后冲撞落空，不追打换入宠物 |
| 控制 | 睡眠、石化等既有阻断行动状态会打断蓄力；首回合先控住 Boss 会压制本次机制 |
| 异常收口 | Boss 死亡／离场会清理意图；宣告前目标倒下才重新选合法目标；伪造或过期意图会被重推导或丢弃 |
| 公开状态 | 客户端只收到 actor ID、显示名、回合与中文提示，不投影目标账号 ID 或用户名 |

机制目录由严格加载器校验回合连续性、合法目标类别、文本占位符、唯一 ID 与 Boss 技能。遭遇地图只负责
声明机制 ID；客户端请求无法提供 Boss、目标、伤害、回合或奖励事实。

## 战斗身份与显示外观

岩脉守护兽继续以 `bui_normal_thick_earth10` 作为战斗身份，因此原有纯土地属性、等级、四项战斗数值、
技能、经验和奖励来源均不改变。战斗显示单独复用已通过正式 12 动作／180 帧门禁的
`wuli_evolved_crystal_earth8_water2` 晶甲外观，并使用唯一显示名 `岩脉守护兽`，不会再自动追加槽位数字。

外观覆盖只允许显式 `catchable=false` 的权威遭遇条目，未知外观或可捕捉条目会让目录加载失败；这避免
玩家捕捉到“显示为晶甲乌力、实际却是厚皮布伊”的身份错配。客户端也只在覆盖 ID 非空时替换外观，普通
宠物收到空覆盖字段时继续使用自己的 `formId`。`岩晶冲撞` 只是玩家可读名称，内部仍复用既有
`pet_bui_charge` 公式。

## 玩家反馈与视觉判断

锁定回合把权威意图映射为两层静态提示：目标脚下是琥珀色双椭圆与四个短刻度，血条左侧是小型三角
警示；消息栏直接写明“防御、换宠，或令其无法行动来打断”。标记不闪烁、不扫描全队、不覆盖单位或
血条，也不把机制 ID、账号字段或 QA 文字暴露给玩家。

## 性能证据

真实 Main 10v10 在启动预热后的连续采样如下；两组均保持 60 FPS：

| 场景 | `draw_battle` | `process_total` |
| --- | --- | --- |
| 普通 10v10 | `2.73–3.45 ms` | `0.06–0.08 ms` |
| 锁定蓄力 10v10 | `3.30–4.21 ms` | `0.08 ms` |

应用启动首个一秒窗口分别为 46.9／43.8 FPS，随后稳定到 60 FPS，因此没有把启动着色器／资源预热样本
混入稳态结论。新增绘制只读取已经映射到 actor 的布尔标记，没有在 `_draw` 中做档案归一化、全目录扫描、
文件 I/O 或网络请求；Boss 场景最差 `draw_battle` 仍低于 Phase 412 已通过的 4.54 ms 参考门槛。
