# Phase 414：潮回守护兽潮核决策窗

## 结论

本阶段完成 P1.5 的第二条可发布切片：服务端权威登记的 `tide_echo_guardian_group` 会在潮回守护兽生命
首次降到 60% 以下时，把潮核寄宿到一只仍存活的同阵营护卫。玩家在下一回合拥有一次明确选择：集火击破
潮核，换取 Boss 一个完整决策回合的退潮弱防窗口；或者继续攻击 Boss／防御，让潮核回流并治疗 Boss。

普通遭遇、切磋、其他守护战和既有自动战斗不获得这套机制。P1.5 父项仍未完成；第三类 Boss 决策以及
PvP 的目标优先、驱散／控制、换宠和资源窗口仍需后续切片。

## 参考意图与原创边界

StoneAge 8.0 只作为成熟回合制游戏“机制先可读，再让玩家改变结果”的行为参考。本阶段没有复制其源码、
数值、地图、美术或具体 Boss 规则。Beastbound 的原创机制只有一次血量阈值、一次潮核选择和两种结果，
没有叠加隐藏层数、倒计时条、强制驱散或额外货币，避免 10v10 信息过载。

## 服务端权威合同

| 项目 | 固定行为 |
| --- | --- |
| 启用来源 | 权威遭遇同时给出 `tide_echo_guardian_group` 与 `guardian_tide_core_v1` |
| Boss 槽位 | 固定 `enemy.front.3`；生命首次降到 `60%` 以下才触发 |
| 潮核目标 | 从存活、非玩家拥有、与 Boss 同阵营且不是 Boss 本人的单位中按房间 seed 确定 |
| 决策期限 | 潮核开启后的下一个回合末结算，期间权威意图持续指向同一 actor |
| 忽略潮核 | Boss 回复最大生命的 `18%`，受最大生命上限约束，机制完成 |
| 击破潮核 | Boss 防御从 `112` 降到 `72`（基础防御的 `65%` 向下取整） |
| 退潮时长 | 弱防保持一个完整决策回合，下一回合末恢复到权威基础防御 `112` |
| 控制关系 | 潮核是回合末阶段事件，不占 Boss 行动；睡眠／石化 Boss 不会阻止开启或结算，核心反制是转火潮核 |
| 异常收口 | Boss 死亡／离场、没有合法护卫或过期状态会清理机制；死亡潮核不再显示标记 |
| 重连安全 | 回合、目标归属、Boss／目标名称和弱防值由服务端重新推导；伪造 Boss 自身、玩家宠或不存在目标均拒绝 |
| 公开状态 | 客户端只收到机制、actor、回合、标记样式与中文提示，不投影账号 ID 或用户名 |

机制目录升级为 schema 2，并按 `targeted_charge`／`tide_core` 分型严格校验。旧的地脉锁定蓄力行为保持
不变；地图只声明机制 ID，客户端不能提交阈值、潮核目标、治疗量、防御值或持续回合。

## 战斗身份与显示外观

潮声洞窟原有遭遇身份 `bui_normal_red_fire10`、等级、数值、技能、奖励来源与捕捉规则不在本切片中改写，
避免把尚未评审的元素／公式调整混进 Boss 机制提交。该 Boss 明确 `catchable=false`，战斗显示使用已经过
正式发布门的 `driftfox_evolved_moon_gale_wind7_water3` 月岚风狐动作包，并以唯一名称“潮回守护兽”出现；
因此不会把外观错配带入可捕捉宠物档案。

这是有边界的战斗装束复用，不等同于新增宠物身份。后续若决定把潮回守护兽正式改为风水元素，必须另做
数值、克制与技能评审；本阶段不把该产品决定藏在美术替换里。

## 玩家反馈与演出语义

潮核目标脚下使用青蓝色双椭圆、短刻度和圆点徽章；它与地脉蓄力的琥珀色环／三角警示在颜色和形状上
都可区分。消息栏只写“本回合集火击破，否则回复 18% 生命”，不显示机制 ID、账号、测试字段或 QA 指令。
标记静止、不闪烁、不遮单位和血条。

服务端事件在客户端使用四种准确演出：潮核开启为 Boss 施法、回流为治疗、潮核击破为 Boss 受创硬直、
退潮结束为 Boss 恢复施法。不再把“潮核击破”错误表现成防御姿态。

最终 1280×720 审片中，左上敌方与右下我方继续朝向战场中心；正式月岚风狐 Boss 与普通护卫有明确
轮廓层级，青蓝潮核标记只出现在一只护卫上，消息文本未越界。`moss_meadow` 仍只是显式 QA 审片背景，
没有扩大为普通玩家运行战场。
