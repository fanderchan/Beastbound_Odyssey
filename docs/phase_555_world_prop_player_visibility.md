# Phase 555：前景岩石遮挡与人物可见性

日期：2026-09-19。主目录 `Beastbound_Odyssey`，基线 `f9da6876c`。

## 问题与边界

真实鼠标试玩复现两处影响探索的问题：一层 `(6,23)` 的前景岩脊完全盖住玩家，二层 `(26,8)` 的岩柱只露出人物头顶。角色仍能移动，但玩家难以辨认自己的位置。原始 38 次 Computer Use 调用及 76 条未改写工具事件保存在 `.run/earth-actions-20260919-retry2/computer-use-tool-transcript.jsonl`，SHA-256 为 `e7bc2025f514972d4787a855add26615b39820403dedecdfc91e473a732fdbc8`；该轮结论是 `FAIL_OCCLUSION`，没有写成完整动作矩阵通过。

根因是 Phase 547 的遮挡处理只纳入 `collisionRole=interaction` 的楼梯、共鸣台，遗漏了普通阻挡物和装饰物。四层都复用这些世界物件，按地图逐项调整位置会掩盖同一渲染缺陷。

只读核对本地 StoneAge 8.0 参考库，未把其中服务端的透明标志推断为已验证的客户端遮挡效果。本次依据实际可见性问题，沿用 Beastbound Phase 547 的 28% 淡化规则。保留脚底深度排序、地图布局、碰撞、寻路、入口、奖励和交互；没有新增设置、提示或美术资源。

## 实现

- `WorldDepthLayer` 在创建深度排序物件时缓存全部世界物件，不再按碰撞用途筛选。地面及固定覆盖层仍走原来的渲染层。
- 物件范围复用 `WorldCameraSafeAreaModel.opaque_world_rect()`，仅建图时读取并缓存纹理有效范围，同贴图复用；清空地图后释放该缓存。
- 玩家遮挡范围复用相机构图已缓存的完整动作轮廓。尚未准备的动作保持保守几何回退，遮挡查询不读取纹理。
- 人物处于物件后方且有效范围相交时淡化；走到前方、离开相交范围或隐藏人物后恢复。静止且几何未变时直接返回。

第一次局部修复已使原隐藏位置的人物可见，但把贴图透明留白也算进遮挡，导致入口岩脊过早变淡。该中间版本的原始证据保留在 `.run/earth-actions-20260919-occlusion-fixed/`，未作为最终通过；最终实现同时收紧人物与物件范围。
