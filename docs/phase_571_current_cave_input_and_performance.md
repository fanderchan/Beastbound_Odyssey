## 正常时钟静止观察

第一段真实鼠标运行保留普通限帧和 VSync，在 Main 初始化后开启计时记录，未使用 `--fixed-fps` 或 `--disable-vsync`。稳定静止区间有 29 个进程采样，实际 `56.340s`，累计进程 CPU 时间增加 `4.890s`，即约 **8.68% CPU**；1680 个实际进程／绘制帧，配置 30 FPS，区间内零失焦、零不可绘制。详细原件见 [正常静止结果](../.run/phase571-manual-actions/normal-idle-summary.json) 及其同目录 `wall-clock-samples.jsonl`。

这是启用诊断和隔离夹具的单窗口观察，不是普通联网玩家基准。它尚未达到项目低个位数 CPU 的健康目标；子毫秒脚本区段不足以解释整个进程。其他手动时段存在面板切换、截图和失焦，不把整段平均数标为稳态移动性能。
