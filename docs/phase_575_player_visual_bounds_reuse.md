# Phase 575：复用人物轮廓键与局部遮挡范围

日期：2026-09-19。继续 R1.W024 性能收口，沿用 Phase 555 的遮挡规则与既有人物比例，不改变地图、相机目标、输入、骑乘合同或服务端权威。

## 定位与实现

四层各运行旧网格／当前美术两个独立 headless Main，预热 180 帧，再用 Godot 脚本分析器记录 480 个静止帧。候选美术每帧都查询人物遮挡范围与相机轮廓签名；网格场景不执行这两项。静止时并未反复扫描地图物件或重新读取贴图，重复工作位于查询内部。诊断在 `.run/phase575-idle-call-comparison/`，这是调用归因，不能代替原生性能门槛。

`Player` 按当前形象、朝向、动作复用轮廓查询键，并在这些字段或骑乘形态改变时更新相机签名。遮挡查询仅缓存从源图轮廓到 Sprite2D 局部矩形的换算；每次核对实际源范围、贴图尺寸、绘制矩形及翻转，每次仍应用当前全局变换。这样父节点移动、旋转、缩放或重新挂接不会留下旧世界坐标。同一动作的轮廓稍后准备、清理或更新也会立即反映；未准备时仍保守回退，不在遮挡查询中读取图片。

局部换算与非缓存的相机范围复用同一数学方法。没有依靠贴图对象身份或单个变更信号判断尺寸，原对象改变尺寸和启用区域也纳入回归。Godot [Sprite2D 实现](https://github.com/godotengine/godot/blob/master/scene/2d/sprite_2d.cpp) 用于核对属性与范围的关系，实际兼容性另由本机 4.7 引擎验证。
