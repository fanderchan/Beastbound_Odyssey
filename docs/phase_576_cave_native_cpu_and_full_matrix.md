## 普通时钟 CPU 对照

二层依次创建网格／美术／美术／网格四个独立 Main，每段连续前台绘制预热 8 秒后测量 20 秒。保留正常时钟、VSync 与静止 30 FPS 上限，关闭音频和存档；未启用 `--debug`、脚本分析器、`--perf-probe` 或固定步长。这是离线隔离夹具的静止对照，不代表普通联网玩家、移动或整游戏验收。

每段观察及实际绘制均为 **601 帧**，零失焦、零不可绘制。每段取得 21 次进程累计 CPU 时间采样，以首尾 CPU 秒数之差除以墙钟秒数之差，乘以 100。下表取同一变体两段结果的平均：

| 变体 | 两次进程 CPU 占用 | 平均占用 | 每帧 draw calls |
| --- | ---: | ---: | ---: |
| 旧网格基线 | 22.980% / 21.751% | 22.366% | 3548 |
| 当前洞穴美术 | 7.686% / 7.881% | 7.784% | 127 |

当前美术在这组对照中的进程 CPU 占用更低。不能把脚本区段相对网格的增量直接解释为整游戏 CPU 增量，也不能据此认定绘制调用、GPU、调频或某个函数是全部原因。两者都是当前代码的不同渲染路径，不是版本修改前后的收益对照；候选 7.784% 仍不能证明已达到正常玩家低个位数 CPU 目标。

原始日志、21 点采样、四段报告、运行身份与清理证明在 [正常时钟对照目录](../.run/phase576-native-cpu-keyboard-20260920/)。目录名沿用准备方案：实际绑定游戏窗口后，日志已确认采样开始，因此没有向该游戏窗口追加键盘、点击或置顶操作，也没有在采样期间截图。
