# Phase 577：人物外观选择缓存

日期：2026-09-20。继续 R1.W024；本次只减少人物外观同步的重复解析，不改变四套形象、人物比例、骑乘、地图、战斗或服务端规则。

## 原因与实现

Main 每帧检查人物／骑乘外观时，都会读取 `appearanceId`、去除首尾空白并查询人物目录。即使档案没有变化，这些解析仍重复发生；Phase 575 的原生脚本分析确认了这条调用路径。

`_selected_player_appearance_id()` 现在保存原始字符串与解析结果。每次仍读取当前档案的字段，只有原始值改变时才调用目录；档案整体替换、嵌套字典原地修改、删除字段都会立即得到正确结果。空白处理和未知形象回退继续由 `CharacterActionAssetCatalog` 负责，查询不修改档案。

目录在单次客户端运行期间只加载一次，因此缓存成立。将来若增加素材目录热更新，必须同步失效这份选择缓存及已有动画缓存。没有添加档案全量比较、宠物扫描或新的逐帧状态归一化。
